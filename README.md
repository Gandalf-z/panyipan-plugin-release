# 盘一盘

> 盘市场，也盘自己。

这是 **盘一盘 Obsidian 插件的安装与更新分发仓库**。

这里不承载盘一盘的开发源码、后端实现、运维配置或任何用户数据，只提供经过发布检查的 Obsidian 插件安装包。

## 安装（当前测试阶段）

盘一盘目前通过 **BRAT** 提供小范围安装与自动更新。

### 第一次安装

1. 在 Obsidian 中打开 **设置 → 第三方插件 → 浏览**。
2. 搜索并安装 **BRAT**，然后启用。
3. 在 BRAT 中选择 **Add Beta plugin / 添加插件**。
4. 输入：`Gandalf-z/panyipan-plugin-release`
5. 选择最新版本并安装。
6. 回到 **设置 → 第三方插件**，启用 **盘一盘**。

> “Beta”是 BRAT 自身沿用的功能名称，不代表盘一盘的产品状态。盘一盘工程环境统一使用 `dev / test / prod`。

## 更新

通过 BRAT 安装后，后续版本可由 BRAT 检查并更新，无需再次手工下载 ZIP、寻找 `.obsidian/plugins` 或复制文件。

## 运行说明

当前公开给测试用户的安装包连接盘一盘 **Test** 服务。用户不需要安装 Python、Runtime、Docker，也不需要配置盘一盘后端。

## 隐私与安全

- 本仓库不包含 DeepSeek Key、Cloudflare 凭据、授权 Secret 或其它服务器凭据。
- 本仓库不包含盘一盘后端源码与开发运维工具。
- 用户的个人交易账本、复盘资料与本地工作区不会因为安装插件而上传到本仓库。

## 手动安装（仅故障备用）

如 BRAT 暂时不可用，可从本仓库 GitHub Releases 下载当前版本的 `main.js`、`manifest.json`、`styles.css` 三个文件进行手动安装。正常情况下不建议使用此方式。
