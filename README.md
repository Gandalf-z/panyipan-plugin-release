# 盘一盘

> 盘市场，也盘自己。

**盘一盘**是面向 A 股主动交易者的个人研究与复盘工具。

这个仓库只用于盘一盘 Obsidian 插件的安装与更新。

## 最快安装

### 1. 安装 BRAT

在 Obsidian 中打开：

**设置 → 第三方插件 → 浏览 → 搜索 `BRAT` → 安装并启用**

也可以尝试直接打开：

[在 Obsidian 中打开 BRAT](obsidian://show-plugin?id=obsidian42-brat)

### 2. 安装盘一盘

BRAT 启用后，点击：

[安装盘一盘](obsidian://brat?plugin=Gandalf-z/panyipan-plugin-release)

如果浏览器没有直接唤起 Obsidian，请在 BRAT 中选择 **Add Beta plugin**，然后输入：

```text
Gandalf-z/panyipan-plugin-release
```

> “Beta plugin”只是 BRAT 自身的功能名称，不代表盘一盘的产品状态。

### 3. 启用盘一盘

安装完成后回到：

**设置 → 第三方插件 → 盘一盘 → 启用**

之后即可开始使用。

## 更新

通过 BRAT 安装后，后续版本可直接由 BRAT 检查并更新，无需重新下载 ZIP，也不需要寻找插件目录或手工覆盖文件。

## 隐私与安全

本仓库只承担插件分发，不保存你的个人交易资料、复盘账本或本地工作区数据，也不包含服务端凭据和运维配置。

## 手动安装

手动下载文件仅作为 BRAT 不可用时的故障备用方式。正常安装请优先使用上面的 BRAT 流程。
